# Satdobato Flyover – VISSIM Transportation Research

## Overview

This repository documents my published research on the performance of the Satdobato Flyover in Lalitpur, Nepal, using microscopic traffic simulation with PTV VISSIM.

The study evaluates the effectiveness of the flyover by comparing transportation performance before and after implementation using key traffic performance measures.

## Research Objectives

- Evaluate the operational performance of the Satdobato Flyover.
- Analyze changes in traffic delay and queue length.
- Evaluate intersection performance using Level of Service (LOS).
- Develop and calibrate a microscopic traffic simulation model using PTV VISSIM.
- Validate the simulation model using field-observed traffic conditions.
- Assess the effectiveness of the flyover in improving traffic operations.

## Methodology

The research involved:

1. Field data collection at the Satdobato Intersection.
2. Development of the intersection network in PTV VISSIM.
3. Traffic demand and movement representation.
4. Model calibration using observed traffic conditions.
5. Model validation using GEH statistics and NRMSE.
6. Simulation of traffic conditions.
7. Evaluation of delay, queue length, and Level of Service.
8. Comparison of intersection performance.

## Software and Tools

- **PTV VISSIM**
- Microsoft Excel
- Statistical analysis and engineering evaluation methods

> Note: This repository documents the original VISSIM-based research. Python and GIS were not used in the original study.

## Key Findings

The study found that the flyover improved the operational performance of the Satdobato–Ekantakuna corridor.

Key improvements included:

- Approximately **51% reduction in overall delay**
- Approximately **55% reduction in average queue length**
- Improvement in **Level of Service from E to D**

The simulation model was calibrated and validated using GEH statistics and NRMSE.
