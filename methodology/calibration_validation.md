# Calibration and Validation

## Calibration

The VISSIM model for the Satdobato Intersection was calibrated using observed traffic conditions collected from field surveys. The calibration process involved adjusting relevant traffic and driver-behavior parameters so that the simulated traffic conditions closely represented the observed field conditions.

The calibration performance was evaluated using the GEH statistic and other comparison measures.

The calibrated model achieved GEH values below 5, indicating a satisfactory match between observed and simulated traffic volumes.

## Validation

Following calibration, the model was validated using independent traffic observations. The simulated results were compared with field observations to assess the reliability of the developed VISSIM model.

The validation results showed that the model reproduced the observed traffic conditions with acceptable accuracy. The NRMSE values were below 30% for the evaluated approaches, except for the Gwarko-to-Ekantakuna movement.

These results supported the use of the calibrated VISSIM model for evaluating the performance of the Satdobato flyover.

## Key Results

- GEH values were below 5 during calibration.
- NRMSE values were below 30% for most evaluated movements.
- The Gwarko-to-Ekantakuna movement showed comparatively higher error.
- The calibrated and validated model was subsequently used to evaluate traffic performance.
